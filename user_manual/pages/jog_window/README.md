# Jog Window

Manual motion control panel for precise positioning.

## Device Selection

Select motion device from dropdown at top of panel.

## Jog Controls

### Direction Buttons
- **X+/X-**: Move along X axis
- **Y+/Y-**: Move along Y axis
- **Z+/Z-**: Move along Z axis
- **U/V/W**: Additional axes (if available)

### Step Sizes

Available step sizes (click to select):

| Step | Use Case |
|------|----------|
| 0.1 µm | Ultra-fine adjustment |
| 0.5 µm | Fine adjustment |
| 1 µm | Precision positioning |
| 2 µm | Small movements |
| 5 µm | Medium movements |
| 10 µm | Standard jog |
| 20 µm | Quick positioning |
| 50 µm | Fast movement |
| 100 µm | Large step |
| 200 µm | Coarse movement |
| 500 µm | Very coarse |
| 1 mm | Millimeter step |
| 2 mm | Large jump |

## Position Display

Current position shown for each axis in real-time.

## Named Positions

- **Go To**: Move to saved position
- **Save**: Save current position with name
- **Delete**: Remove saved position

## Safety

- Always start with smaller step sizes
- Verify motion range before large movements
- Use waypoints for complex paths
