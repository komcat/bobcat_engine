# Main Menu

Application home screen and product management.

## Header Bar

| Element | Description |
|---------|-------------|
| **Product: XXXXX** | Current product name (red text) |
| **Path** | Product configuration file path |
| **AUX** (blue) | Open Auxiliary Display window |
| **JOG** (orange) | Open Jog Window for manual motion |

## Product Management

### Current Product
Displays active product name in header bar.

### Product Buttons

| Button | Color | Function |
|--------|-------|----------|
| **New Product** | Purple | Create new product configuration |
| **Load Product** | Blue | Open existing product |
| **Save** | Green | Save current product |
| **Save As...** | Yellow | Save product with new name |
| **Delete Product** | Red | Remove product configuration |

## Navigation Tiles

### Top Row

| Tile | Function |
|------|----------|
| **Process** | Open Run Program Page - execute recipes |
| **Recipe** | Open Recipe Page - edit process steps |
| **Motion** | Open Motion Control Page - device management |

### Bottom Row

| Tile | Function |
|------|----------|
| **Hardware Instrument** | Hardware device configuration |
| **Edit Config** | Edit configuration files |
| **Vision Manager** | Camera and vision settings |

## Status Bar (Bottom)

| Element | Description |
|---------|-------------|
| **[INFO]** | System status messages |
| **Warning indicators** | Hardware connection status |
| **Full Log** | Open detailed log viewer |

## Quick Access

- **AUX button** - Always visible for quick access to camera/chart view
- **JOG button** - Always visible for manual positioning

## Typical Workflow

1. **Load Product** - Select product configuration
2. **Recipe** - Create or edit process recipes
3. **Process** - Execute program with recipes
4. **JOG** - Manual adjustments as needed
