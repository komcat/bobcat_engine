RECIPE PAGE - POPUP SUPPRESSION
================================================================================
Date: 2025-10-29
Feature: Suppress confirmation and success popups during recipe execution

================================================================================
WHAT WAS CHANGED
================================================================================

Suppressed two QMessageBox popups that interrupted recipe execution:

1. Confirmation Popup (BEFORE execution)
   - Previously asked: "Execute recipe 'xxx' with N step(s)?"
   - Required user to click "Yes" to proceed
   - NOW: Removed - execution starts immediately when Run button is clicked

2. Success/Error Popup (AFTER execution)
   - Previously showed: "Recipe 'xxx' completed successfully!" or error message
   - Required user to click "OK" to dismiss
   - NOW: Removed - status shown in progress widget, logged to LogManager

================================================================================
USER EXPERIENCE CHANGES
================================================================================

BEFORE:
  1. User clicks "▶ Run Recipe"
  2. Popup appears: "Execute recipe 'xxx' with N step(s)?"
  3. User must click "Yes"
  4. Recipe executes
  5. Popup appears: "Recipe 'xxx' completed successfully!"
  6. User must click "OK"
  7. Progress widget auto-dismisses after 3 seconds

AFTER:
  1. User clicks "▶ Run Recipe"
  2. Recipe executes immediately (no popup)
  3. Progress widget shows execution status in real-time
  4. On completion, progress widget shows "✓ Completed!" or "✗ Failed"
  5. Progress widget auto-dismisses after 3 seconds (no popup required)
