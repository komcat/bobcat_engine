================================================================================
XCAN PLUGIN SPECIFICATION
================================================================================

**Process Name:** XCAN
**Category:** Motion Control
**Description:** Hexapod adaptive scanning (coarse/fine) to find optimal alignment

**Parameters:**
1. device - Hexapod device name (must match hex-* pattern)
   - Type: Device selector (Motion devices)
   - Default: "hex-left"
   - UI Label: "Hexapod Device (hex-*)"

2. mode - Scan mode selection
   - Type: Text field
   - Default: "coarse"
   - Valid values: "coarse" or "fine"
   - UI Label: "Scan Mode (coarse/fine)"

3. channel - Data channel to optimize
   - Type: Text field
   - Default: "" (empty, user must specify)
   - UI Label: "Data Channel"
   - Examples: "PD_Signal", "OpticalPower", etc.

4. settling_time_ms - Motion settling time
   - Type: Numeric (integer)
   - Default: 300
   - Range: 50-2000 ms
   - Step: 10 ms
   - UI Label: "Settling Time (ms)"

CODE DETAILS
================================================================================

XCANPlugin Class Structure:
------------------------------------------------------------

class XCANPlugin : public IProcessPlugin
{
public:
  // 1. Process identification
  std::string GetName() const override {
    return "XCAN";
  }

  std::string GetCategory() const override {
    return "Motion Control";
  }

  std::string GetDescription() const override {
    return "Hexapod adaptive scanning (coarse/fine) to find optimal alignment";
  }

  // 2. Default parameter values
  std::map<std::string, std::string> GetDefaultParameters() const override {
    return {
      {"device", "hex-left"},
      {"mode", "coarse"},
      {"channel", ""},
      {"settling_time_ms", "300"}
    };
  }

  // 3. UI widget creation
  void CreateConfigUI(ProcessConfigWidget* widget, const ProcessInstance* instance) override {
    const auto& params = instance->parameters;

    // Device selector - Motion devices
    widget->addDeviceSelector("device", "Hexapod Device (hex-*)",
      params.at("device"),
      static_cast<int>(DeviceComboBox::DeviceType::Motion));

    // Mode text field
    widget->addParameterField("mode", "Scan Mode (coarse/fine)",
      params.at("mode"));

    // Channel text field
    widget->addParameterField("channel", "Data Channel",
      params.at("channel"));

    // Settling time numeric spinner
    widget->addNumericParameter("settling_time_ms", "Settling Time (ms)",
      params.at("settling_time_ms"),
      50,     // min value
      2000,   // max value
      10,     // step size
      0,      // decimals (integer)
      "ms"    // suffix
    );
  }

  // 4. Sequence generation
  void BuildSequence(SequenceBuilder* sequence, const ProcessInstance* step) override {
    const auto& params = step->parameters;
    std::string device = params.at("device");

    // Add XCAN command to sequence
    sequence->AddAction(device, "XCAN", {
      {"mode", params.at("mode")},
      {"channel", params.at("channel")},
      {"settling_time_ms", params.at("settling_time_ms")}
    });

    std::cout << "[MotionProcesses] Built XCAN sequence for: "
              << step->userNickname
              << " (mode=" << params.at("mode")
              << ", channel=" << params.at("channel") << ")"
              << std::endl;
  }
};

================================================================================
USER WORKFLOW
================================================================================

Adding XCAN to Recipe:
------------------------------------------------------------

1. Open RecipePage
2. In "Available Processes" panel, find "XCAN" under "Motion Control" category
3. Click "XCAN" or drag it to the Recipe Steps list
4. Configure parameters in right panel:
   - Select hexapod device (hex-left or hex-right)
   - Enter scan mode: "coarse" or "fine"
   - Enter data channel name (e.g., "PD_Signal")
   - Adjust settling time if needed (default 300ms)
5. Optional: Edit process nickname for clarity
6. Click "Save Recipe" to save

Executing Recipe with XCAN:
------------------------------------------------------------

1. Load recipe containing XCAN step
2. Click "Run Recipe" button
3. Recipe execution will:
   - Execute steps in order
   - When reaching XCAN step, perform adaptive scan
   - Log progress to execution log
   - Continue to next step upon completion
4. Monitor progress in log output
5. Use "Stop" button to halt if needed

- Channel name checked against DataStore
- Clear error messages returned if validation fails
