================================================================================
WHY THESE CHANGES
================================================================================

DataStore Member:
- SequenceContext is execution-scoped, not for persistent data
- DataStore is the correct place for sensor data reading
- Other handlers (DataStoreCommandHandler) also take DataStore
- MotionCommandHandler needs DataStore for XCAN scanning

AdaptiveScanController Arguments:
- Constructor signature: (UnifiedMotionManager&, DataStore&, deviceName, dataChannel)
- Need all 4 arguments for proper initialization
- Missing channel caused compile error

Stop Flag API:
- SequenceContext uses method-based API, not direct member access
- IsStopRequestedAny() checks both context flag and engine callback
- More robust than direct member access
