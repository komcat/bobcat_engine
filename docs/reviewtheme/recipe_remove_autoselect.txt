================================================================================
RECIPE PAGE - AUTO-SELECT NEXT STEP ON REMOVAL
================================================================================
Date: 2025-10-29
Feature: Automatically select the next step after removing a recipe step

================================================================================
PROBLEM BEFORE
================================================================================

When removing a recipe step:
1. User selects a step in the recipe tree
2. User clicks "Remove" button
3. Confirmation popup appears: "Are you sure you want to remove this step?"
4. User clicks "Yes"
5. Step is removed, BUT no step is selected anymore (m_selectedStepIndex = -1)
6. User must manually click on another step to select it
7. User can then remove that step
8. Repeat...

This made removing multiple consecutive steps very tedious and slow.

================================================================================
SOLUTION IMPLEMENTED
================================================================================

After removing a step:
1. The next step (that moved into the deleted position) is automatically selected
2. The configuration form is updated to show the newly selected step
3. User can immediately click "Remove" again without clicking
4. Also suppressed the confirmation popup for faster workflow

================================================================================
FILES MODIFIED
================================================================================

File: include/AppUI/RecipePage/RecipePage.cpp
Method: onRemoveStep() (lines 1059-1103)

Changes:
1. Commented out confirmation popup (QMessageBox::question)
2. Remember the deleted step index
3. After removal, calculate which step to select next:
   - If deleted step was in the middle: select same index (next step moved up)
   - If deleted the last step: select the new last step (index - 1)
   - If no steps left: clear selection (-1)
4. Call selectStepByIndex() to select in the tree
5. Call updateConfigurationForm() to show the selected step's config

================================================================================
CODE LOGIC
================================================================================

Before (problematic):
```cpp
void RecipePage::onRemoveStep()
{
  if (m_selectedStepIndex < 0) return;

  QMessageBox::StandardButton reply = QMessageBox::question(...);

  if (reply == QMessageBox::Yes) {
    m_recipeManager->removeStep(m_selectedStepIndex);
    refreshRecipeList();
    clearConfigurationForm();
    m_selectedStepIndex = -1;  // ❌ Clears selection!
  }
}
```

After (improved):
```cpp
void RecipePage::onRemoveStep()
{
  if (m_selectedStepIndex < 0) return;

  // ✅ No confirmation popup

  int deletedIndex = m_selectedStepIndex;
  m_recipeManager->removeStep(m_selectedStepIndex);
  refreshRecipeList();

  int newTotalSteps = m_recipeManager->getStepCount();

  if (newTotalSteps > 0) {
    // Select next step or previous if deleted last
    if (deletedIndex >= newTotalSteps) {
      m_selectedStepIndex = newTotalSteps - 1;
    }
    else {
      m_selectedStepIndex = deletedIndex;
    }

    // ✅ Auto-select and show config
    selectStepByIndex(m_selectedStepIndex);
    updateConfigurationForm();
  }
  else {
    m_selectedStepIndex = -1;
    clearConfigurationForm();
  }
}
```
