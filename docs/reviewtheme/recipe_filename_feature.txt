================================================================================

file is currently being worked on.

- When no recipe loaded: "No recipe file" (gray, dim styling)

================================================================================
IMPLEMENTATION DETAILS
================================================================================

updateRecipeFileNameDisplay() Method:
1. Gets current recipe file path from RecipeManager
2. If path is empty:
   - Shows "No recipe file" with dim gray styling
3. If path exists:
   - Extracts just the filename using QFileInfo
   - Shows "Recipe: {filename}" with highlighted cyan styling

File Name Extraction:
- Uses QFileInfo to extract filename from full path
- Example: "config/SIPH0G888/recipes/my_recipe.json" → "my_recipe.json"
- Only displays the filename, not the full path

Update Triggers:
- Loading a recipe (manual load or auto-load)
- Saving a recipe (Save or Save As)
- Creating a new recipe (clears to "No recipe file")
- Auto-loading recipe on application start
